About HourglassPost

A small, independent, free tool for keeping your real inbox clean.

HourglassPost is an independent free tool that gives anyone a throw-away email address in one click. It's for the moments when a website demands an email before you can download a file, read an article or try a product, and you'd rather not hand over your real inbox.

Why "HourglassPost"?

Like sand in an hourglass, every inbox here runs out. Messages last about an hour and then they're gone, which is exactly the point.

What we care about

  • Simplicity: no sign-up, no app, no settings. Open the page and you have an address.
  • Privacy: no cookies, analytics, ads or trackers of our own, and remote images in emails are blocked.
  • Honesty: temporary inboxes are public and short-lived, and we say so plainly so nobody loses an important account.
  • Lightness: plain HTML, CSS and JavaScript, so it loads fast even on slow mobile connections.

How it's made

HourglassPost is a static website hosted for free on GitHub Pages. Mailboxes come from Guerrilla Mail's free public API. HourglassPost is not affiliated with or endorsed by Guerrilla Mail. The source code is public on GitHub. Read how it works for the details.

Keeping it free

HourglassPost is free to use. If an optional way to support the project is ever added, it will always stay optional and the tool will stay free.
